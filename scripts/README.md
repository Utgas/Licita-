# scripts/

- `compilar-regras.ts` (Marco 0): lê as matrizes, confere IDs, referências e JSON Logic e gera o pacote em `regras/`.
- `simular-wizard.ts` (Marco 1): `npm run simular -- C1` monta a minuta de um cenário (C1 a C8, R1, R2) e imprime em texto corrido, com as pendências e a contagem de lacunas por motivo no fim.
