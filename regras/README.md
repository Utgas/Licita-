# regras/

Pacotes de regras gerados pelo compilador (`npm run compilar`) a partir de `matrizes/`. Um subdiretório por versão do modelo AGU, por exemplo `agu-tr-compras-2025-12/`, com `pacote.json` e `pacote.sha256`.

Não edite nada aqui à mão. Para mudar uma regra, mude a matriz e compile de novo.
